AI Content Studio V6 - 무료 로컬 이미지 AI 연결

중요
- 이 ZIP은 유료 API를 사용하지 않습니다.
- Pexels API 기능을 제거했습니다.
- 이미지 생성은 내 컴퓨터에서 실행되는 Stable Diffusion 호환 서버를 사용합니다.
- 프로그램에서 먼저 1장만 시험하도록 만들었습니다.
- 권장 시험 크기: 384 x 512, 4 steps

연결 조건
1. Stable Diffusion WebUI AMDGPU 또는 Forge처럼
   /sdapi/v1/txt2img API를 지원하는 무료 프로그램을 설치합니다.
2. 이미지 프로그램을 API 옵션으로 실행합니다.
   예시 실행 옵션: --api --use-directml
3. 이미지 프로그램 주소가 http://127.0.0.1:7860 이어야 합니다.
4. AI Content Studio에서 "첫 장 AI 이미지 시험"을 누릅니다.

주의
- AI 모델 파일은 용량이 매우 커서 이 교체용 ZIP 안에는 포함하지 않았습니다.
- 첫 실행과 모델 로딩에는 시간이 걸릴 수 있습니다.
- 메모리 부족 시 Ollama를 잠시 종료하고 이미지 1장만 생성한 뒤 다시 켜세요.
- 처음부터 8장 자동 생성하지 않고 각 카드의 버튼으로 한 장씩 시험합니다.
