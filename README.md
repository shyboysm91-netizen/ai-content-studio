# AI Content Studio V8

무료 Ollama 기반 건강 캐러셀 제작 프로그램입니다.

## V8 핵심 변경

- 기획 → 작성 → 안전 검수의 3단계 AI 생성
- 대상 독자 선택 추가
- 과장·완치·해독·근거 없는 수치 자동 점검
- 임신·약물·보충제 안전 문구 강화
- 카드 중복과 구체성 자동 검사
- 콘텐츠 검수 점수 및 통과 항목 표시
- 캡션·해시태그 복사 버튼
- 기존 3D 일러스트, PNG, ZIP 기능 유지

## 실행

```powershell
npm install
npm run dev
```

브라우저: `http://localhost:3000`
